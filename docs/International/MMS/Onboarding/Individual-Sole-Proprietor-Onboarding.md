# Individual / Sole Proprietor Onboarding

Streamlined flow for C0/C1 merchants. Simplified KYC (individual identity document). No parent linkage required.

**Eligibility check:** MSISDN not already registered as a Merchant.

## Phases

1. MSISDN Operator Pre-check
2. Merchant Registration Check (MMP)
3. OTP Verification
4. KYC Capture and Registration
5. MMP Checker Review
6. Alias Creation (SHID + MBNO via PI-RAC)
7. Account Synchronization
8. AML Verification
9. Compliance Officer Review
10. Merchant Notification (SMS with Reference Number, MID, and Shortcode)

See also: [Merchant Profile Management](../Merchant-Profile-Management) for C0/C1/C2 tier definitions, [Alias Management](../../Merchant-Portal/Alias-Management) for SHID/MBNO/MCOD details.
