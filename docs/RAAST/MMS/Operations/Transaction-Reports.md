# Transaction Reports

The following reports are available in the Backoffice Portal.

## Summary Reports

| Report | Description |
|---|---|
| Aggregator Commission Summary | Aggregator list and commission earned for a given date/range. |
| Merchant Payout Summary | All merchant payments via RAAST — net payment summary, aggregator-wise and merchant-wise. |

## Detailed Reports

| Report | Description |
|---|---|
| Aggregator Commission Detail | Commission detail per transaction for each aggregator. |
| Merchant Payout Detail | Net payment details per transaction for each merchant. |

## Additional Reports

- All QR Transactions Report — approved, declined, timed out.
- Merchant Payment Exception Report — approved but not captured/settled.
- Merchant Payment Report — approved and settled transactions.
- QR Merchant Onboarding Report — Daily, Monthly, as-on-date.
- QR Merchant Cancellation Report — Daily, Monthly, as-on-date.
- QR Merchant Sales Report.
- QR Merchant Sales Report by Region.

## Report Search Criteria

- From Date / To Date
- Transaction Status: All / Completed / Failed / TIP
- Transaction Type: All / RTP Now / RTP Later / DQRC / Account

For settlement-specific report formats (columns, extracts for reconciliation), see [Settlement Reports](../../Settlement/Reconciliation-Data-Points) and the existing [Settlement Features](../../Merchant-portal/Functional-specification/Settlement-Features) reference.
