# Transaction View

Detailed transaction view provides full drill-down capability for any individual transaction.

| Requester | Action(s) / Process Description |
|---|---|
| Backoffice User | Selects a transaction from the monitoring list. Clicks 'View Details'. |
| Backoffice Services | Fetches full transaction details including request/response logs. |
| Backoffice Portal | Displays complete transaction details with the following views (below). |

## Transaction Detail Views

- **Channel Request & Response** — raw request from channel and response returned.
- **Host Request & Response** — request sent to CBS and CBS response.
- **RAAST Request & Response** — ISO 20022 messages sent to and received from RAAST SBP.

See also: [Transaction Monitoring](./Transaction-Monitoring), [Transaction Reports](./Transaction-Reports).
